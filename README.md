# Hollowmere — The Ashen Vigil

A complete original dark fantasy action RPG built with Three.js. Explore a haunted village, defeat twelve afflicted creatures, and silence the Bellkeeper.

## Run

Requires Node.js 20 or newer. No installation or build service is needed: the pinned Three.js 0.180.0 runtime is included locally.

```sh
npm run dev
```

Open **http://127.0.0.1:5182**. The static game is in `dist/` and can be served by any static web server. A WebGL2-capable browser is required. Sound begins after the first interaction.

## Controls

| Action | Control |
| --- | --- |
| Move | WASD / arrow keys / click ground |
| Target and cleave | Click a creature; hold to chase and attack |
| Stand and cleave | Shift + left click |
| Emberbolt | Right click |
| Evade | Space |
| Cinder nova | E |
| Healing draught | Q |
| Journal / map / pause | J / M / Escape |

Touch devices have a movement stick and ability buttons with automatic enemy aiming. Red ground indicators show enemy attacks before they resolve. Evade grants brief invulnerability. Essence regenerates; every fourth afflicted kill restores one healing draught. The game pauses when the tab loses focus.

## Generated assets

Five original articulated GLB models are generated by `scripts/generate-assets.mjs`: Warden, Hollow, Grave Hound, Cinder Revenant, and Bellkeeper. Twelve original synthesized PCM WAV effects cover combat, footsteps, healing, ambience, and bells. These are procedural assets generated locally, rather than third-party or AI service downloads. Regenerate them with `npm run generate`.

The village uses merged scenery geometry, instanced cobbles and grass, shadowed moonlight, animated torchlight, drifting ash, and a shader portal. Creature parts are merged by material while retaining animated limb groups.

## Validation

```sh
npm test
npm run build
```

The checks cover combat geometry, cooldown and resource rules, health and death, collision and pathfinding, progression, GLB structure and numeric buffers, WAV headers, script syntax, and asset/DOM references.

Optional browser WebMCP integration exposes `get_vigil_state` and `control_warden` through the same game rules and controls. Browsers without it run the game normally.
